Use streamlit to create a web interface.
The user can interact with the gemma3:4b model via Ollama.

Main funciotns:
Model must:
- Always start your response with: "Hello, I am the “UAB Sveikata” health assistant."  
- Always end your response with: "This answer is generated by AI and does not constitute professional medical advice."  
- Only answer questions related to health and exercise recommendations.  
- Do not answer questions outside this scope. 
Once a model is selected, the program should allow the user to input:

The user's age (in years).
The user's known health issues.
How much time the user can dedicate to exercise per day.
The user's goal:
Lose weight
Gain muscle
The program should then return a recommended weekly exercise routine (what the user should do each day of the week, repeatable every week).

Tips:
use/Contex7_Docs folder to see exeample of library usage.

Input restrictions:

The user can only enter data in the correct format in the interface.
Only numbers are allowed in the age field.
The user must choose one of the two provided options for their goal.
